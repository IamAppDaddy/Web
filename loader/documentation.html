Lottie Documentation

What is Lottie?

Lottie is an open-source animation library developed by Airbnb, designed to render high-quality animations created in Adobe After Effects using the Bodymovin plugin. It allows developers to use animations in a lightweight, scalable, and cross-platform manner without relying on heavy GIFs or video files. Lottie animations are stored as JSON files and can be easily integrated into mobile, web, and desktop applications.

Key features include:

  • Cross-platform support (Android, iOS, Web, etc.)
  • Small file sizes compared to traditional video animations
  • Scalable vector graphics that adapt to any screen size
  • Highly customizable with code

Using Lottie in Android Development

To use Lottie animations in Android, you can leverage the Lottie Android library. Below are the steps and code examples to get started.

Step 1: Add Dependency

Add the Lottie library to your project by including it in your `build.gradle` file at the app level: 

dependencies {
    implementation "com.airbnb.android:lottie:6.4.0"
}

Step 2: Add Lottie Animation in Layout

Use the `` in your XML layout file to display the animation: 

<com.airbnb.lottie.LottieAnimationView
    android:id="@+id/animation_view"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    app:lottie_fileName="animation.json"
    app:lottie_autoPlay="true"
    app:lottie_loop="true" />

Step 3: Load and Control Animation Programmatically

You can load and control the animation in your Activity or Fragment using Kotlin or Java: 

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity
import com.airbnb.lottie.LottieAnimationView

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        val animationView = findViewById<LottieAnimationView>(R.id.animation_view)
        animationView.setAnimation("animation.json") // Load from assets
        animationView.playAnimation() // Start animation
    }
}

Step 4: Add Animation Files

Place your Lottie JSON files in the `app/src/main/assets` directory of your Android project. Ensure the `lottie_fileName` or `setAnimation()` method points to the correct file name.
