Snake Game
Documentation

Overview

Control a black snake to eat green food and grow longer on a white canvas using arrow keys or swipes in this smooth, classic Snake game built in one HTML file.

Gameplay

Snake is a classic arcade game where players control a black snake on a white canvas to eat green food, growing longer with each bite. Navigate using arrow keys or swipe gestures, avoiding collisions with the snake's own body. The game offers smooth gameplay with a 15px grid and 20 FPS, featuring clear start and game over screens with black and white text for readability.

Controls

  • Arrow Keys: Use Up, Down, Left, Right keys to change the snake's direction.
  • Swipe Gestures: Swipe up, down, left, or right on the screen to move the snake.
  • Start/Restart: Press any arrow key or swipe on the start or game over screen to begin or restart the game.

Features

  • Smooth gameplay with a 15px grid and 20 FPS for fluid movement.
  • Black snake and green food on a white background for clear visuals.
  • Responsive design optimized for mobile devices with touch controls.
  • Clear start screen with black text and game over screen with white text on a dark overlay.
  • Built in a single HTML file for simplicity and portability.
