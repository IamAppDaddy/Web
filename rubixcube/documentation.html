The Cube

Documentation for the Ultimate Cube-Solving Experience

Overview

"The Cube" is a sleek, interactive 3D Rubik's Cube game designed for mobile. Solve the cube as fast as possible with intuitive touch controls and customizable settings tailored for speedcubing enthusiasts and casual players alike.

How to Play

  • Start the Game: Double-tap the screen to begin. The timer starts when you make your first move.
  • Rotate the Cube: Swipe left, right, up, or down to rotate cube faces. Use touch gestures to manipulate the cube in 3D.
  • Timer: A real-time timer tracks your solve time, displayed prominently on the screen.
  • Complete the Cube: Align all faces to a single color to solve the cube. See "Complete!" and possibly "Best Time!" if you set a new record.

Customization Options

Tap the settings button to access options for personalizing your gameplay:

  • Cube Size: Select 2x2x2, 3x3x3, 4x4x4, or 5x5x5 cubes.
  • Flip Type: Choose rotation animations: Swift, Smooth, or Bounce.
  • Scramble Length: Set the number of random moves (20, 25, or 30).
  • Camera Angle: Toggle between Orthographic and Perspective views.
  • Color Scheme: Pick themes like Cube, Erno, Dust, Camo, or Rain.
  • Custom Colors: Adjust Hue, Saturation, and Lightness sliders to create custom cube colors.

Statistics

View your progress by tapping the stats button:

  • Cube Size: Shows the current cube size (e.g., 3x3x3).
  • Total Solves: Tracks your total completed solves.
  • Best Time: Displays your fastest solve time.
  • Average of 5/12/25: Shows average solve times over the last 5, 12, or 25 solves.

Platform Compatibility

"The Cube" is optimized for mobile devices:

  • Android: Render the game in an Android app using a WebView for a smooth experience.
  • iOS: Use a WebView to run the game in an iOS app, optimized for iPhones and iPads.
  • Web: Load the game file in a mobile browser for instant play without installation.

Technical Notes

  • Powered by Three.js for high-quality 3D rendering.
  • Custom touch-friendly sliders and icons enhance the mobile experience.
  • Uses the "Bowlby One" font for a bold, modern look.
