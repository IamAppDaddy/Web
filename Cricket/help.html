Doodle Cricket Developer Documentation

Overview

This documentation outlines the development of a responsive, single-page Doodle Cricket game with green branding. The game is built using HTML, CSS, and JavaScript, with a focus on simplicity and accessibility.

Setup Instructions

  • Ensure index.html and doodle-cricket.svg are in the same directory.
  • Open index.html in a modern browser (e.g., Chrome, Firefox) to run the game.
  • No external dependencies are required; all code is embedded in this file.

game-folder/

How to Play Doodle Cricket

  1. Start the Game: Open index.html in a modern browser (e.g., Chrome, Firefox) to launch Doodle Cricket.
  2. Choose Your Team: Select your cricket team from the available options on the start screen.
  3. Hit the Ball: Use the mouse or keyboard (arrow keys or spacebar) to swing the bat when the ball is bowled.
  4. Score Runs: Time your swing to hit the ball and score runs. The better the timing, the farther the ball goes!
  5. Avoid Getting Out: Miss the ball three times, and you're out. Watch the bowler's delivery closely!
  6. Chase the Target: Try to score more runs than the opposing team before your overs run out.
  7. Win the Match: Beat the target score to win, or defend your score if you're batting first.
